# Модуль управления каталогом товаров

Учебный проект курсовой работы МФЮА на тему «Разработка модуля управления каталогом товаров для интернет-магазина».

Планируются Python, FastAPI, Jinja2, SQLAlchemy и SQLite. Локальная система разработки и демонстрации — macOS.

## Документация

- [Требования, анализ методических материалов и план курсовой](docs/PLAN.md).
- [Проектирование: структура, база данных, экраны, маршруты и проверки](docs/DESIGN.md).

## Состояние

Анализ и проектирование подготовлены. Код приложения, база данных и зависимости пока не созданы. Следующий этап — подготовка среды и минимального FastAPI-приложения после согласования со студентом.

Основные функции: управление товарами и категориями, поиск, фильтрация, сортировка и учет текущих остатков. Демонстрационный ассортимент — канцелярские товары.
