# Модуль управления каталогом товаров

Курсовой проект на тему «Разработка модуля управления каталогом товаров для интернет-магазина».

Автор: Чемоданов Никита Сергеевич, группа 23ИПо8381 (ИПо-41). Руководитель: Колпащиков Кирилл Александрович.

Программа хранит товары и категории в SQLite. В браузере доступны добавление, просмотр, изменение и удаление записей, поиск, фильтры и сортировка. Категорию с товарами удалить нельзя. Модуль рассчитан на локальную работу; авторизация и обработка заказов не реализованы.

Стек: Python 3.12, FastAPI, Jinja2, SQLAlchemy, SQLite, Uvicorn.

## Установка и запуск на macOS

Скачайте репозиторий и откройте его папку:

```bash
git clone https://github.com/Koryza/kyyyyyrsach.git
cd kyyyyyrsach
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
```

Дождитесь сообщения `Application startup complete` и откройте http://127.0.0.1:8000/. Для остановки нажмите Control+C.

При повторном запуске из папки проекта:

```bash
source .venv/bin/activate
python -m uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
```

База `data/catalog.db` создаётся автоматически и сохраняется после остановки. Для нового каталога сначала создайте категорию, затем товар. Демонстрационные 1200 товаров в 12 категориях можно добавить командой:

```bash
python -m scripts.seed_demo
```

Перед загрузкой примеров существующая база копируется в `data/backups/`. Повторная загрузка и сохранение своих записей описаны в [DEMO_DATA.md](docs/DEMO_DATA.md).
