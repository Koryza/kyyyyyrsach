# Пояснительная записка

- [Редактируемый Word](coursework_draft.docx).
- [PDF для просмотра](coursework_draft.pdf).
- [Исходный текст](DRAFT.md).
- [Библиография из 20 источников и проверка](SOURCES.md).
- [Задание, предоставленное пользователем: Word](assignment.docx) и [PDF](assignment.pdf).

Версия от 21.10.2026 подготовлена для проверки студентом и руководителем. **Объём — 28 страниц без приложений**, 32 страницы вместе с четырьмя страницами приложения. Служебная страница первоначального черновика удалена. Введение занимает две страницы, заключение — две. На титуле заполнены ФИО, специальность, дисциплина, кафедра, профиль, курс, полная группа, руководитель и город по заданию и ответу пользователя.

Структура: титул, содержание, введение, три главы по три параграфа, заключение, список использованных источников и приложение. Пять таблиц описывают подходы, требования и проверки, поля модели, компоненты и фактические результаты. Две схемы созданы редактируемыми элементами Word; четыре иллюстрации приложения — настоящие снимки программы.

Базовое оформление: A4, поля 30/10/20/20 мм, основной текст Times New Roman 14, интервал 1,5, абзац 1,25 см; главы, введение, заключение, источники и приложение начинаются с новой страницы. Оглавление использует закладки и PAGEREF. Его кэш заполнен номерами проверенного PDF; после изменения текста поля нужно обновить. При открытии на другом компьютере пагинация может зависеть от шрифтов; PDF фиксирует просмотренную версию.

Программа фактически использует SQLite. Упоминание PostgreSQL в задании относится к основным источникам информации; в записке объяснены сравнение вариантов и пределы переноса. Работа на PostgreSQL не приписана проекту. Сведения о тестах и наборе из 1200 товаров взяты из выполненных проверок, а не из предположений о нагрузке.

Задание сохранено без изменения текста. Оно не включено в 28 страниц записки и предоставлено отдельным файлом для комплектации по правилам вуза. Подписи, утверждение, даты приёма задания, отзыв, оценка и результат проверки оригинальности не имитируются.

Список из 20 источников удовлетворяет общему минимуму 15 записей. Его состав смешанный: учебные книги, стандарты и документация из перечня задания. Рекомендация о 15–20 научных источниках и предел проверки ГОСТ 19.201–78 объяснены в [SOURCES.md](SOURCES.md); не следует называть этот список 20 научными публикациями. Окончательное академическое решение остаётся за руководителем и вузом.

## Повторная сборка

Для изменения сборки используются необязательные зависимости, не нужные серверу:

```bash
python -m pip install -r requirements-docs.txt
python -m scripts.build_coursework
```

Команда пересоздаёт Word и PowerPoint из DRAFT.md, bibliography.json, student.json и снимков. PDF после этого экспортируется заново из Word/LibreOffice и PowerPoint/LibreOffice. Поля оглавления нужно обновить после экспорта или редактирования. Ручные правки Word/PPTX при повторной сборке заменяются: их следует переносить в исходный текст либо сохранять отдельно.

Сведения о проверенных файлах — [artifacts-checked.json](artifacts-checked.json). Остаток процедур перед сдачей — [PROJECT_STATUS.md](../PROJECT_STATUS.md).
