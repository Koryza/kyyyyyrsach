Базовое оформление: A4, поля 30/10/20/20 мм, Times New Roman 14, интервал 1,5, абзац 1,25 см, новые главы с новой страницы. Титул составлен по полям предоставленного шаблона; неизвестные кафедра, дисциплина, профиль, ФИО, курс, группа, руководитель и город отмечены для заполнения. Утверждения и подписи не имитированы. Окончательное соответствие шаблону проверяется после заполнения этих полей.

Документ действительно открыт LibreOffice и экспортирован в PDF. Просмотрены страницы, исправлена лишняя пустая страница; таблицы сохранены целиком, заголовки и изображения не обрезаны. Снимки приложения не сгенерированы: они получены Chromium. Набор из 1200 товаров и результаты его проверки описаны в DEMO_DATA.md.

## Повторная сборка

Готовые файлы открываются без инструментов Python. Для изменения сборки в отдельном окружении нужны необязательные зависимости:

```bash
python -m pip install -r requirements-docs.txt
python -m scripts.build_coursework
```

Команда пересоздаёт Word и PowerPoint по текущему тексту и снимкам. PDF после этого нужно заново экспортировать из Word/LibreOffice и PowerPoint/LibreOffice. Число страниц зависит от установленных шрифтов; PDF в репозитории фиксирует проверенную облачную версию. Ручные изменения Word/PPTX при повторной сборке заменяются, поэтому их нужно сохранить отдельно либо перенести в исходный текст/скрипт.
