# Технические первоисточники для рабочей записки

Это реестр шести проверенных первоисточников, а не законченный список литературы по ГОСТ. Исходные страницы официальной документации недоступны из текущей облачной сети (HTTP 403 при установлении соединения). Поэтому 21.10.2026 прочитаны исходники этих документов в официальных GitHub-репозиториях; каждый адрес ниже вернул HTTP 200. Сеть ради обхода ограничения не расширялась. Машинные сведения о полученных текстах и контрольные суммы — в [sources-verified.json](sources-verified.json).

Обозначения `[T1]`–`[T6]` в рабочем тексте временные. При сборке записки нужно оформить записи по ГОСТ 7.0.100-2018, назначить сквозные номера и заменить ссылки. Номера страниц для непагинированных веб-документов не придуманы. Текущие ветки репозиториев могут изменяться; дата доступа относится к реально прочитанной копии, а не к дате издания.

Эти технические документы не заменяют требуемую вузом подборку научной литературы. Минимум 15 источников по новой методичке и рекомендация 15–20 научных источников по документу об антиплагиате пока **не выполнены**. Статьи, книги, выходные данные и номера страниц не добавлены без проверки. Для главы 1 ещё нужны изученные научные публикации о моделировании каталога, целостности реляционных данных, веб-архитектуре и функциональном тестировании. Состав списка и допустимость документации как части библиографии определяет преподаватель.
