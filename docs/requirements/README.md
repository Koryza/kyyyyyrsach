# Технические требования к модулю каталога

- [Редактируемый Word](technical_requirements.docx).
- [PDF для просмотра](technical_requirements.pdf).
- [Исходный текст](REQUIREMENTS.md).

Документ от 27.10.2026 подготовлен для проекта «Разработка модуля управления каталогом товаров для интернет-магазина». Автор — Чемоданов Никита Сергеевич, группа 23ИПо8381 (ИПо-41), 4-й курс.

Структура следует предоставленному образцу: группы функциональных требований с кодами ПТ и отдельные бизнес-правила БП. Дополнительно приведены нефункциональные и технические требования НФТ. Всего 23 пункта ПТ, 12 правил БП и 8 пунктов НФТ. В проверенном PDF — 5 страниц.

Требования описывают текущий объём модуля: один менеджер, товары и категории, поиск, фильтры, сортировка, пагинация, общие правила HTML и API, SQLite и сохранение данных. Авторизация, несколько ролей, заказы и оплата в объём не включены.

Оформление Word: А4, поля по 25,4 мм, Times New Roman 14 пт для основного текста, интервал 1,5. Коды требований выделены жирным; разделы выровнены по центру. В PDF используется замена Liberation Serif, поскольку Times New Roman отсутствует в среде экспорта. Для окончательного PDF с этим шрифтом откройте Word на компьютере с установленным Times New Roman и экспортируйте заново.

## Повторная сборка

Из корня проекта после установки `requirements-docs.txt`:

```bash
.venv/bin/python -m scripts.build_requirements
```

Команда пересоздаёт только Word с техническими требованиями из `REQUIREMENTS.md`. PDF после изменения текста экспортируется отдельно через Word или LibreOffice. Основная пояснительная записка и презентация этой командой не изменяются.
