Документ от 27.10.2026 задаёт требования к разработке модуля управления каталогом товаров. Автор — Чемоданов Никита Сергеевич, группа 23ИПо8381 (ИПо-41), 4-й курс.

Спецификация устанавливает назначение, границы, пользовательские потребности, функции системы, атрибуты предметной области, правила данных, ограничения, свойства качества, системные характеристики и порядок приёмки. В ней нет результатов испытаний, ссылок на готовый код, конкретных имён его полей или привязки к выбранным библиотекам. Средства и структура реализации должны определяться на этапе проектирования.

Уровни разделены: ПТ — возможности менеджера; ФТ — требуемые действия системы; БП — правила предметной области; НФТ — свойства качества. Всего 23 пункта ПТ, 15 требований ФТ, 12 правил БП, 8 пунктов НФТ, 15 ограничений ОГР, 14 системных характеристик СХ и 14 приёмочных сценариев ПР. Описаны 12 логических атрибутов категории и товара.

В проверенном PDF — 12 страниц. Оформление Word: А4, поля по 25,4 мм, Times New Roman 14 пт, интервал 1,5; в пяти таблицах — 12 пт. Заголовки таблиц повторяются, строки не разрываются между страницами. В облачном PDF используется Liberation Serif вместо отсутствующего Times New Roman. Для окончательного экспорта с требуемым шрифтом используйте Word на компьютере с установленным Times New Roman.

## Повторная сборка

Из корня проекта после установки `requirements-docs.txt`:

```bash
.venv/bin/python -m scripts.build_requirements
```

Команда пересоздаёт Word из `REQUIREMENTS.md`; PDF экспортируется отдельно. Протокол соответствия, основная пояснительная записка и презентация этой командой не изменяются.
