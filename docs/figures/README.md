# Снимки приложения

Снимки получены Playwright в Chromium в облачной Linux-среде 21.10.2026. Использован учебный ассортимент канцелярских товаров в отдельной временной SQLite-базе. На снимках показаны страницы приложения с тестовыми товарами; рабочие данные пользователя не использованы. Версия браузера, размеры экранов, время и перечень пройденных сценариев сохранены в [browser-report.json](browser-report.json).

Снимки фиксируют разные шаги одного сценария, поэтому цена и остаток между карточкой и последующими экранами меняются. Товар удаляется только после снятия этих кадров. Источник иллюстраций: собственная разработка и её тестовый прогон. В пояснительную записку включены четыре изображения с номерами А.1–А.4. На них есть ссылки в разделе 3.3, под каждым снимком приведены подпись и источник.

## Большой каталог

Для проверки большого списка подготовлен набором из 1200 товаров. Снимки этого набора находятся в [large-catalog/](large-catalog/): список, фильтры и 12 категорий по 100 товаров; отчёт — [report.json](large-catalog/report.json). Файлы `04-catalog-viewport.png` и `05-catalog-slide.png` — дополнительные снимки видимой области браузера для Word и презентации, с экранами 1440 × 960 и 1440 × 760. Это отдельный набор от первоначальных девяти снимков выше.

## Изменения текста интерфейса

22.10.2026 сокращены подзаголовки и уточнены подсказки. Снимки выше сохраняют надписи версии от 21.10.2026; они не переснимались при редактуре. Операции и структура страниц сохранены.

Позднее 22.10.2026 по требованию студента удалены декоративные значки меню, кнопок и ссылок. На снимках от 21.10.2026 они ещё присутствуют; файлы сохраняют исходные результаты проверки.
