# Реальные снимки приложения

Снимки получены Playwright в Chromium в облачной Linux-среде 21.10.2026. Использован учебный ассортимент канцелярских товаров в отдельной временной SQLite-базе. Это реальные страницы разработанного приложения; персональные и рабочие данные пользователя в них не использованы. Версия браузера, размеры экранов, время и перечень пройденных сценариев сохранены в [browser-report.json](browser-report.json).

Снимки фиксируют разные шаги одного сценария, поэтому цена и остаток между карточкой и последующими экранами меняются. Товар удаляется только после снятия этих кадров. Источник иллюстраций: собственная разработка и её тестовый прогон. В пояснительной записке перед изображением нужна ссылка в тексте, под ним — подпись «Рисунок N — …». Нумерацию назначить после сборки всей записки. Не считать готовой вёрстку PNG-документов оформлением Word.
