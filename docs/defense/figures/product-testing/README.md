# Проверка продукта для презентации

09.11.2026 пройдены 14 сценариев Chromium 154.0.8037.57 на экранах 1440 × 1000 и 390 × 844. Приложение работало на отдельном сервере scripts.check_server с новой временной SQLite-базой. Рабочая база не открывалась.

[browser-report.json](browser-report.json) содержит полный список сценариев и три подробных сопоставления результатов для слайда 9. Они входят в число 14 и не прибавляются к нему отдельно.

| Проверка | Ожидалось | Получено |
|---|---|---|
| Создать товар с ценой 49,90 руб. и остатком 24 | Сохранить указанные значения | В карточке и API цена 49,90 руб., остаток 24 |
| При редактировании указать цену 1.234 | Отклонить значение, не менять запись | Ответ 422, видимое сообщение об ошибке; запись совпадает с прежней, цена 49,90 руб. |
| Удалить категорию с товарами | Отказать и сохранить связанные записи | В интерфейсе нет кнопки подтверждения; сервер вернул 409, категория и товар доступны через API |

Для повторения запустить `.venv/bin/python -m scripts.check_server`, затем в другом терминале выполнить:

```bash
python scripts/browser_check.py --output /tmp/catalog-product-testing --chromium /usr/bin/chromium
```

Для скрипта нужен Python с Playwright. После штатной остановки сервера временная база удаляется. Новый прогон pytest и шесть сценариев большого каталога в рамках этой проверки не выполнялись.
