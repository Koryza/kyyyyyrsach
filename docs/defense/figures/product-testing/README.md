# Проверка продукта для презентации

09.11.2026 повторно пройдены 154 автоматических теста и 14 сценариев Chromium 154.0.8037.57. Браузер работал на экранах 1440 × 1000 и 390 × 844. Приложение запускалось через scripts.check_server с отдельной временной SQLite-базой.

- [Протокол pytest](automated-tests.xml): 154 теста, ноль ошибок и провалов.
- [Браузерный отчёт](browser-report.json): 14 сценариев.
- [Условия итогового прогона](run-summary.json), включая исправление изоляции одного теста.

Шесть подробных проверок входят в 14 браузерных сценариев и отдельно к ним не прибавляются.

| Проверка | Ожидалось | Получено |
|---|---|---|
| Создать товар | 49,90 руб., 24 единицы | Цена и остаток совпали с заданными |
| Указать цену 1.234 | Отказ без изменения записи | 422, запись совпадает с прежней, цена 49,90 руб. |
| Изменить цену и остаток | 54,90 руб., 18 единиц | Оба значения подтверждены через API |
| Удалить занятую категорию | Отказ с сохранением связанных записей | 409; категория и полный список её товаров сохранены |
| Отменить удаление товара | Сохранить запись | 200, данные товара не изменились |
| Подтвердить удаление товара | Сделать запись недоступной | При чтении товара API вернул 404 |

Карточка после создания содержит цену 49,90 руб. и остаток 24. Затем проверяется неверная цена; после отказа выполняется допустимое изменение на 54,90 руб. и 18 единиц. Поэтому изображения показывают разные этапы одного прогона. Для вставки в слайды кадрирование выполняется в PowerPoint; исходные PNG не меняются.

Повторить автоматические тесты из корня:

```bash
.venv/bin/python -m pytest -q --junitxml=/tmp/catalog-automated-tests.xml
```

Для браузерных сценариев запустить `.venv/bin/python -m scripts.check_server`, затем в другом терминале:

```bash
python scripts/browser_check.py --output /tmp/catalog-product-testing --chromium /usr/bin/chromium
```

Нужен Python с Playwright. После штатной остановки сервера временная база удаляется. Шесть сценариев большого каталога от 21.10.2026 в новый прогон не входят. Нагрузка и одновременное редактирование несколькими менеджерами не проверялись.
