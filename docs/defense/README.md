# Презентация защиты

- [PowerPoint: 8 редактируемых слайдов](catalog_defense.pptx).
- [PDF для просмотра](catalog_defense.pdf).
- [Речь, демонстрация и ответы на вопросы](../DEFENSE.md).

В презентации показаны задачи модуля, модель данных, обработка запроса и экран каталога. Отдельные слайды посвящены демонстрационным данным, тестам и ограничениям. У каждого слайда есть заметки докладчика, доступные в режиме заметок PowerPoint. В титуле заполнены ФИО Чемоданова Никиты Сергеевича, группа 23ИПо8381 (ИПо-41), 4-й курс, дисциплина, руководитель Колпащиков Кирилл Александрович и город Киров.

Цифры соответствуют фактической версии проекта: 1200 демонстрационных товаров, 12 категорий, 133 товара без наличия, 154 автоматических теста. Браузерные результаты разделены: 14 основных сценариев интерфейса и 6 дополнительных сценариев большого каталога. Производительность и работа в действующем магазине не проверялись.

После редактуры 22.10.2026 презентация пересобрана и экспортирована LibreOffice Impress; просмотрены все восемь слайдов PDF. Схемы состоят из редактируемых фигур, скриншот получен из приложения. PDF не включает заметки докладчика. Перед защитой проверить реквизиты и требования преподавателя к длительности, отрепетировать речь с демонстрацией.

Сборка слайдов выполняется командой `python -m scripts.build_coursework` после установки `requirements-docs.txt`; после изменения PPTX нужен новый экспорт PDF. Подробности — в [инструкции документов](../coursework/README.md).
