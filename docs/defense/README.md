# Презентация защиты

- [PowerPoint: 8 редактируемых слайдов](catalog_defense.pptx).
- [PDF для просмотра](catalog_defense.pdf).
- [Речь, демонстрация и ответы на вопросы](../DEFENSE.md).

Презентация содержит цель, модель данных, архитектуру, реальный экран каталога, большой демонстрационный набор, результаты проверки и направления развития. У каждого слайда есть заметки докладчика, доступные в режиме заметок PowerPoint. В титуле заполнены ФИО Чемоданова Никиты Сергеевича, группа ИПо-41, дисциплина, руководитель Колпащиков Кирилл Александрович и город Киров.

Цифры соответствуют фактической версии проекта: 1200 демонстрационных товаров, 12 категорий, 133 товара без наличия, 154 автоматических теста. Браузерные результаты разделены: 14 основных сценариев интерфейса и 6 дополнительных сценариев большого каталога. Это не измерение производительности и не результаты внедрения.

PPTX экспортирован настоящим LibreOffice Impress, просмотрены все 8 слайдов PDF. Схемы состоят из редактируемых фигур, скриншот получен из приложения. PDF не включает заметки докладчика. Перед защитой проверить реквизиты и требования преподавателя к длительности, отрепетировать речь с демонстрацией.

Сборка слайдов выполняется командой `python -m scripts.build_coursework` после установки `requirements-docs.txt`; после изменения PPTX нужен новый экспорт PDF. Подробности — в [инструкции документов](../coursework/README.md).
