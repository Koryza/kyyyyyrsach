## Браузерный прогон

Результат: **14 сценариев пройдены**. Полный перечень и фактическая версия Chromium — в [машинном отчёте](figures/browser-report.json). Сценарии включают CRUD через формы, цену с запятой, серверную ошибку цены с сохранением ввода, совместные фильтры, переход 10 + 3 товара, отсутствие результатов, защиту категории, мобильный список и форму, отмену удаления, подтверждённое удаление, отсутствие ошибок JS и создание категории при отключённом JavaScript.

Снимки в [figures/](figures/README.md) получены из настоящего приложения на учебном ассортименте. Они не подтверждают внедрение магазина или работу реальных пользователей.

Для воспроизведения запустить в первом терминале из корня:

```bash
.venv/bin/python -m scripts.check_server
```

Во втором терминале — Python с установленным Playwright:

```bash
python scripts/browser_check.py --output /tmp/catalog-browser-report --chromium /usr/bin/chromium
```

Путь Chromium в примере относится к проверенной облачной среде. При необходимости установить Playwright в отдельное окружение проверки и указать путь к своему Chromium. Этот инструмент не нужен для обычного запуска приложения. Сервер использует только `127.0.0.1:8001`, база создаётся в `TemporaryDirectory`; после штатной остановки она удаляется. Скрипт браузера до изменений проверяет специальный признак тестового сервера и пустой список товаров. Для повторного прогона остановить тестовый сервер Control+C и запустить его заново. Не направлять сценарий на рабочую базу.

## Найденные проблемы и исправления

| Проблема | Исправление | Проверка |
|---|---|---|
| Скрытый заголовок таблицы расширял документ на мобильном экране | Контейнер таблицы получил `position: relative` | Итоговый прогон проверяет `scrollWidth <= innerWidth` для списка и формы |
| Flex на ячейке нарушал высоту последнего столбца | Flex перенесён во вложенный блок | Осмотр реального снимка списка |
| Очень большой ID HTML-страницы мог выйти за диапазон SQLite | Ограничения пути `ge=1`, `le=SQLITE_MAX_INTEGER` | Дополнительные отрицательные тесты HTML |
| В сообщении цены повторялось имя поля | Устранён повтор префикса | Осмотр снимка ошибки после исправления |

Дополнительные 29 HTTP-проверок API с перезапуском на временной базе выполнены на этапе 5; это предыдущий отдельный прогон, он описан в [STAGE_5.md](STAGE_5.md). Он не суммируется с числом pytest-тестов.

## Пределы проверки

Пройденные сценарии подтверждают учебные функции каталога. Нагрузочное тестирование, одновременное редактирование несколькими пользователями и другие браузеры не проверены. Авторизация, история движения остатков и миграции схемы не реализованы в согласованном объёме первой версии. Сервер рассчитан на локальную демонстрацию менеджером.
