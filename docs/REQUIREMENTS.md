# Требования к модулю и учебной работе

Тема: «Разработка модуля управления каталогом товаров для интернет-магазина».

Основание — [выданное задание](coursework/assignment.pdf) и требования к оформлению, зафиксированные при разборе предоставленных методических материалов МФЮА. Исходные методические файлы в репозиторий не включены. Окончательные требования к комплектации определяет руководитель.

## Назначение и границы

Пользователь модуля — менеджер каталога, работающий локально. Приложение ведёт товары и категории, показывает текущие цены и остатки. Демонстрационный ассортимент — синтетические канцелярские товары.

В реализованную версию не входят авторизация, оплата, заказы, доставка, загрузка изображений, варианты товаров и журнал складских движений. Хранение текущего остатка не заменяет учёт приходов, списаний и резервирования.

## Функциональные требования

| Требование | Критерий проверки |
|---|---|
| Создание, чтение, изменение и удаление товара | Изменения видны после повторного чтения; при редактировании сохраняется идентификатор |
| Ведение категорий | Пустую категорию можно удалить; категорию с товарами удалить нельзя |
| Поиск | Поиск части названия работает с русским текстом без учёта регистра |
| Фильтры | Категория, включительные границы цены и наличие применяются совместно |
| Сортировка | Доступны название, цена и время изменения; равные значения упорядочены по идентификатору |
| Пагинация | До 10 товаров на странице; переходы сохраняют фильтры |
| Ошибки формы | Ввод сохраняется, причина отказа отображается текстом |
| Подтверждение удаления | Открытие подтверждения читает данные; удаление выполняется отдельным POST |
| Хранение | Обычная SQLite-база сохраняет записи после остановки и повторного запуска |
| Два интерфейса | HTML и JSON API используют общие операции каталога |

## Ограничения данных

- Название категории: 1–100 символов; товара: 1–200. Крайние пробелы удаляются.
- Нормализованное имя категории и артикул товара уникальны. Названия товаров могут совпадать.
- Артикул: 1–64 латинских буквы, цифры, дефис или подчёркивание; хранится в верхнем регистре.
- Товар ссылается на существующую категорию. Внешние ключи SQLite включаются для каждого соединения.
- Цена передаётся строкой рублей, хранится целыми копейками. Допустимы ноль и не более двух дробных знаков; скрытого округления нет.
- Остаток — неотрицательное целое число в пределах SQLite. Логические и дробные значения отклоняются входной схемой.
- Описание необязательно, до 2000 символов. Пустое описание хранится как NULL.
- Даты создаются программой в UTC; браузер может показывать местное время.

## Оформление записки

По уточнению преподавателя требуется не менее 30 страниц от введения до списка источников. Титул, содержание, сама библиография и приложения в этот объём не включаются. В проверенном PDF — 32 страницы основного текста, страницы 3–34; источники начинаются на странице 35.

| Параметр | Принятое оформление |
|---|---|
| Бумага | А4 |
| Поля | Слева 30 мм, справа 10 мм, сверху и снизу 20 мм |
| Основной шрифт | Times New Roman, 14 пт |
| Межстрочный интервал | 1,5 |
| Абзац | 1,25 см |
| Выравнивание | По ширине |
| Структура | Введение, три главы по три параграфа, заключение, источники, приложение |
| Начало крупных разделов | С новой страницы |
| Источники | Сквозная нумерация, ссылки в тексте; неподтверждённые реквизиты не добавляются |

Технические ограничения текущего PDF и порядок финального экспорта приведены в [SUBMISSION.md](SUBMISSION.md).

## Академические процедуры

Перед сдачей нужны просмотр руководителем, действительные подписи и даты, отзыв и проверка оригинальности в системе МФЮА. В предоставленных материалах указан ориентир 60%; фактического отчёта и решения преподавателя в репозитории нет.

Допустимый характер помощи ИИ следует согласовать с преподавателем. В методических материалах не установлен разрешённый процент ИИ-контента; в отзыве руководитель обосновывает необходимость сгенерированного текста. Подготовка технической документации не отменяет этих требований.

Общий минимум библиографии — 15 записей. Текущий список содержит 20 источников смешанного состава. Рекомендация о 15–20 научных источниках требует отдельного согласования состава: документация и стандарты не считаются научными статьями только по факту включения в список. Подробности — в [SOURCES.md](coursework/SOURCES.md).
