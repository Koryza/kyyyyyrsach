**Этап 3. Подготовка среды и начального приложения**

Цель — получить повторяемый запуск небольшого FastAPI-приложения и понять путь от команды запуска до ответа браузеру. Управление товарами и база данных относятся к следующим этапам.

**Что создано**

| Файл | Назначение |
|---|---|
| `app/__init__.py` | Обозначает папку `app` как пакет Python |
| `app/main.py` | Создает FastAPI-приложение и два начальных маршрута |
| `.python-version` | Указывает версию Python 3.12 для поддерживающих этот файл инструментов |
| `.gitignore` | Исключает окружение, кэши, локальные настройки и будущую рабочую базу из Git |
| `requirements.txt` | Точные версии библиотек приложения и их зависимостей |
| `requirements-dev.txt` | Подключает зависимости приложения и фиксирует инструменты будущих тестов |
| `README.md` | Команды подготовки, запуска и проверки для macOS и облачной машины |

В облачной машине создано и наполнено окружение `.venv`. Оно находится на диске, но не входит в репозиторий. На своем Mac студент создает отдельное окружение из тех же файлов зависимостей.

Python в облаке — 3.12.14. Основные установленные пакеты: FastAPI 0.154.0, Uvicorn 0.54.0, SQLAlchemy 2.1.5, Jinja2 3.1.6, Pydantic 2.14.1, python-multipart 0.0.32. Для дальнейших проверок установлены pytest 9.1.1 и HTTPX 0.28.1. SQLAlchemy, Jinja2 и обработка форм подготовлены как общие зависимости, но пока не используются в начальных маршрутах.

**Как устроен код**

Актуальный исходный файл — [app/main.py](../app/main.py).

- `from fastapi import FastAPI` подключает класс фреймворка.
- `app = FastAPI(...)` создает объект приложения. Название и описание отображаются в документации, версия `0.1.0` обозначает начальное состояние проекта.
- `@app.get("/")` связывает GET-запрос к главному адресу с функцией `read_root`.
- `read_root` возвращает словарь с сообщением о проекте. FastAPI преобразует его в JSON-ответ.
- `@app.get("/health")` связывает отдельный адрес с функцией проверки ответа сервера. Ее ответ — `{"status":"ok"}`.
- `dict[str, str]` описывает тип ответа: словарь, в котором ключи и значения являются строками.

Команда `python -m uvicorn app.main:app` запускает сервер Uvicorn, загружает модуль `app/main.py` и находит в нем объект `app`. Параметр `--reload` удобен при локальной разработке: после изменения Python-файлов сервер запускает приложение заново.

`/health` подтверждает, что сервер способен обработать запрос. Пока приложение не подключается к базе данных, этот адрес не проверяет ее работоспособность.

На следующих этапах главная страница будет изменена согласно проекту. Сейчас JSON-ответ нужен для понятной проверки первого запуска. Автоматически созданные `/openapi.json` и `/docs` описывают текущие маршруты. Для отображения интерфейса Swagger браузер загружает файлы из CDN.

**Выполненные проверки**

Проверки сделаны в облачной Linux-среде с Python 3.12.14 через реально запущенный Uvicorn, а не прямой вызов функций Python.

| Проверка | Результат |
|---|---|
| Установка в отдельное окружение из `requirements-dev.txt` | Успешно |
| `pip check` | `No broken requirements found` |
| GET `/` | 200; JSON содержит ожидаемое сообщение |
| GET `/health` | 200; JSON `{"status":"ok"}` |
| GET `/openapi.json` | 200; корректный JSON, версия приложения и оба GET-маршрута присутствуют |
| GET `/docs` | 200; HTML содержит подключение Swagger UI и адрес схемы |
| GET несуществующей страницы | 404 |
| Повторное выполнение скрипта установки | Успешно; зафиксированные пакеты уже установлены, `pip check` без ошибок |
| Остановка собственного сервера и повторный запуск с `--reload` | Успешно; все пять HTTP-проверок повторно пройдены |
| Загрузка готовых пакетов для macOS 11+ Apple Silicon, Python 3.12 | Успешно; весь применимый набор зависимостей загружен |
| Загрузка готовых пакетов для macOS 11+ Intel, Python 3.12 | Успешно; весь применимый набор зависимостей загружен |

Проверка `/docs` относится к HTTP-ответу HTML; визуальная работа Swagger в браузере студента проверяется отдельно на Mac. Автотесты товарного каталога пока не созданы и не запускались; пять указанных HTTP-проверок не являются отчетом pytest.

**Проверка на Mac и критерий завершения**

Команды приведены в [README](../README.md). Студенту нужно подтвердить, что в локальном окружении используется Python 3.12.x, установка проходит без ошибки, Uvicorn запускается, главный адрес и `/health` возвращают ожидаемый JSON, а в `/docs` можно выполнить запрос с кодом 200.

До этого этап остается в работе в части локальной проверки macOS. Облачная проверка и наличие установочных пакетов не доказывают запуск на конкретном компьютере.
